# ESPRI 质子能量分析

模拟与实验的分布边缘难以对齐，分析时对两者统一选取 **55°≤θp≤70°** 区间。

## 输入

左右臂分别处理，输入为：

- NaI 沉积能量
- 局域 RDCX
- 局域 RDCY
- NaI 棒编号 `NaIBarID`（整数 1–14，作为第四个标量输入）

输入顺序为 `[ENaI, RDCX, RDCY, NaIBarID]`，网络为 `4→64→64→64→1`。

模拟棒编号取与 `ENaI` 相同的最大能量读出：Left/arm 0 使用 `NaIBarID = 7-GetNaIEId(hit)`，
Right/arm 1 使用 `NaIBarID = 8+GetNaIEId(hit)`。
模拟 Left 的原始棒号须反序，Right 保持原序；统一后 Left 为 1–7、Right 为 8–14，均按 RDCY 从高到低排列。
实验 `espriNaiBarId` 为 0–6，统一映射为 `7*(1-espriSide)+espriNaiBarId+1`，不翻转棒顺序。
Left 对应实验 side 1；Right 对应实验 side 0。

先运行 `PreProcess.C` 生成训练与独立评价的四个 ROOT 文件，再依次运行
`EspriEnergy.ipynb`、`EspriEnergyEvaluation.ipynb`、`ForExperiment.ipynb`。
必须重新训练四输入模型；三输入旧模型不能用于新的预测 Notebook。

## 输出

质子的能量。

## 事件筛选

- 质子同时击中塑闪和 NaI。
- 近似排除击穿 NaI 的事件。

## 结果记录：MLP 质子动能偏低及 NaI 棒号的影响（2026-10-24）

### 质子动能与激发能谱

在当前实验样本上，MLP 预测的质子顶点动能相对原 `protonEnergy` 整体偏低。
四输入模型在 39,860 条 `ComparisonOK` 事件上的平均动能差
`ProtonEnergyNN − protonEnergy` 为 **−1.469 MeV**（左右臂合并）。
两种重建使用相同的 `protonTheta` 和束流参数；在当前运动学区间，质子动能偏低会使缺失质量重建的激发能偏高。
因此，MLP 激发能谱的基态和第一激发态均向高能方向移动，峰位没有更接近已知能级 0 和 3.368 MeV。
这里的原 `protonEnergy` 是实验已有重建结果，并非已知真值；上述差异是两种重建之间的比较。

### 增加 NaIID 输入后的比较

文中的 NaIID 对应代码和 ROOT 分支中的 `NaIBarID`。
三输入模型使用 `[ENaI, RDCX, RDCY]`，四输入模型增加 `NaIBarID`，其他训练参数和物理筛选保持一致。
棒号已按实验位置对齐：模拟 Left 使用 `7-localID`，Right 使用 `8+localID`；
实验使用 `7*(1-espriSide)+espriNaiBarId+1`。

### 最新结果：峰附近独立单高斯拟合

实验比较沿用 **55°≤θp≤70°、Backtracking Z 5σ、Phi12 cut**，同源有效样本为 **39,860 条**。
按要求，基态和第一激发态分别只拟合一个高斯，**不加本底、不加入相邻峰、不共享峰参数**。
采用非分箱扩展似然，每个局部高斯的产额、μ、σ 独立变化，按对应窗口归一化。
各谱使用相同 2 MeV 宽的峰附近窗口；窗口随峰位调整，事件本身没有平移，窗口内事件数可以不同。

| 方法 | 基态窗口 (MeV) | 第一激发态窗口 (MeV) |
|---|---:|---:|
| 原实验重建 | −1.0～1.0 | 2.3～4.3 |
| 四输入 MLP | −0.3～1.7 | 3.0～5.0 |

以下为左右臂合并结果，单位 MeV；误差仅含拟合统计误差。

| 态 | 原实验 μ | 四输入 MLP μ | 原实验 σ | 四输入 MLP σ |
|---|---:|---:|---:|---:|
| 基态 | −0.0338 ± 0.0198 | 0.6602 ± 0.0208 | 0.6788 ± 0.0255 | 0.6957 ± 0.0274 |
| 第一激发态 | 3.3129 ± 0.0087 | 3.9890 ± 0.0096 | 0.6698 ± 0.0111 | 0.7049 ± 0.0129 |

独立高斯拟合下，MLP 两个峰的峰位仍偏高，σ 未小于原实验重建；这里比较的是局部峰形宽度，不是探测器本征分辨率。
窗口半宽另取 0.8 和 1.2 MeV 的检查保存在 JSON 中；局部实际事件成分及拟合窗口会影响 σ。
合并原重建基态的 Poisson deviance/ndf 约 1.69，单高斯并非完全描述局部峰形，不能只凭收敛状态解释物理分辨率。

### NaIID 对谱形影响较小：历史比较的范围

此前三输入与四输入使用相同的“双高斯加指数本底”方法比较：增加 NaIID 后，基态 μ 变化约 +0.0210 MeV、σ 增大约 3.1%；
第一激发态 μ 变化约 +0.0128 MeV、σ 增大约 1.3%。因此，本次加入 NaIID 对实验激发能谱的影响较小，未见期望的改善。
这些数值属于历史带本底拟合，不能与上表独立单高斯参数混用。当前目录缺少三输入版本的逐事件激发能缓存，
本次没有对三输入版本重做独立高斯拟合；新增 NaIID 的收益若按新方法量化，需要同样重拟合三输入原谱。
上述小变化没有进行相关误差的显著性检验，也不代表完整系统误差评估。

### MLP 质子动能偏低的可能原因

以下是基于现有代码和产物的排查假设，尚未确定哪一项主导实验差异。

1. **模拟与实验的探测器响应可能不完全一致。** 已确认模型在模拟上训练，再应用到实验；模拟 ENaI 是带分辨率展宽的读出，实验输入为标定后的 naiEnergy。
   NaI 分棒增益、非线性响应、位置依赖、减速片及其他材料的实际能损若与模拟有差异，都会改变“NaI 读出能量→顶点质子动能”的映射。
   这些差异是否存在、大小及偏移方向仍需用标定和分棒结果验证，不能仅由峰位偏高反推出某个参数有误。

2. **训练和实验应用的停止事件选样不完全相同。** PreProcess.C 使用同臂塑闪/NaI 符合，并通过模拟交互记录施加近似停止判据 `Edep_NaI >= K_after_first_step`。
   ForExperiment.ipynb 没有对应的停止真值筛选。因此，若实验中保留了临界击穿、多棒分能或其他未被训练样本充分覆盖的事件，模型可能低估部分事件的顶点动能。
   目前尚未确定这些事件的比例，也不能把整个偏差都归因于击穿。

3. **输入信息可能不足以确定逐事件的能损修正。** 当前输入为 ENaI、RDCX、RDCY、NaIBarID，没有直接提供塑闪 ΔE、完整径迹方向、逐事件靶点和入射方向等额外信息。
   对相近输入，不同穿行路径及未观测能损仍可能对应不同顶点动能。NaI 棒号又与 RDCY 有较强的位置关联，额外信息可能有限；这是其增益较小的可能解释，而非已完成的因果验证。

4. **损失函数不保证平均动能偏差为零。** 当前采用标准化标签上的 SmoothL1Loss，beta=0.01，按标签标准差换算约为 0.37 MeV。
   较大残差受到近似线性惩罚，训练目标没有直接约束实验基态峰位或激发能 σ。若条件残差不对称，最优回归结果仍可能带有平均偏差。
   独立模拟中，Left/Right 的能量残差均值为 −0.1344/−0.1395 MeV，中位数为 +0.0081/−0.0149 MeV；均值更负提示低估尾部可能影响平均值。
   但这组“预测减模拟真值”与实验“预测减原重建”不是同一参考量，不能直接用前者解释全部实验偏移。

5. **原实验重建也可能存在标定或模型误差。** 相对原 protonEnergy 偏低，并不等于相对真实动能具有同样大小的偏差；原重建采用的材料能损、角度和标定同样需要独立检验。
   激发能计算还使用固定束流总动能 1500 MeV 和实验 protonTheta。它们会影响绝对峰位；不过两种重建使用相同参数时，当前两谱之间的变化直接来自所替换的质子动能。

可区分这些原因的检查包括：按臂、角度、NaI 棒及能量比较残差和峰位，核对实验/模拟能量定义与停止事件组成，并利用独立标定样本检查能量尺度。
目前没有证据把全部差异归结为网络层数不足；更深的网络也不能自动消除输入响应或选样不一致。
