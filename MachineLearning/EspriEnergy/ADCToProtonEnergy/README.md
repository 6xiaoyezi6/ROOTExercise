# ESPRI：从 NaI 能量输入到 ADC 输入

## 研究目的与当前结论

在投入大量时间开发 Geant4 光学模拟之前，先利用已有 Birks 刻度关系，从当前模拟 NaI 能量反向生成等效 ADC，检验网络对于 ADC 表示的适应性。
这一步已完成：ADC 输入的训练、独立模拟评估和真实实验数据推理均已运行，完整流程可用。
总体 RMSE 与原能量输入方案接近，支持 ADC 表示的可行性；但右臂核心误差有所增大，不能概括为所有指标均不变。
目前尚未证明真实 ADC 端到端重建具有精度优势，也未完成 Geant4 双端光学/电子学响应模拟。

## 已完成的内容

1. `EspriADC.ipynb`：以 `[ADC, rdcX, rdcY, NaIID]` 预测顶点质子动能 `ETrue`（MeV），左右臂独立训练；模型保存到 `ADC_output/`。
2. `EspriADCEvaluation.ipynb`：加载完整模型及训练归一化，评估独立模拟数据；结果保存到 `Eval/`。
3. `ForADCExperiment.ipynb`：读取真实实验 ADC，完成同事件能量、能角图、激发能谱及局部峰拟合对照；结果保存到 `Exp/`。
4. 输出了逐事件结果、误差统计和诊断图；固定目录衔接三个 Notebook，重复运行覆盖同名结果。

模拟按每个 NaI 棒读取 `naiCalibOutput.txt_v22` 中的 A、B、C，使用
$$
E_{NaI}=\frac{AQ}{1+BQ}+C,\qquad ADC=Q=\frac{E_{NaI}-C}{A-B(E_{NaI}-C)}.
$$
这里生成连续 ADC，不取整、不额外加噪声；反算异常时报错并停止。评估复用模型保存的标定快照。

实验从 `naiQPed[4][7]` 取所选棒两端扣除 pedestal 后的信号，计算几何平均 ADC：
$$
ADC=\sqrt{\mathrm{naiQPed}[2\,side][bar]\;\mathrm{naiQPed}[2\,side+1][bar]}.
$$
其中 `side=espriSide`、`bar=espriNaiBarId`（0–6），两端均须为有限正数。
Left/side=1 的 NaIID 为 1–7；Right/side=0 的 NaIID 为 8–14；RDC 坐标单位为 mm。
实验直接使用测得的 ADC，不从 `naiEnergy` 反算；原 `protonEnergy` 仅作传统重建对照，不是真值。

## 当前结果：与原能量输入方案比较

以下数值来自现有结果文件，只读取已有结果，未重新训练或拟合。
两方案内部 Test 的 SourceEntry 顺序和真值一致；独立 Eval 的输入文件 SHA256 相同，左右臂分别为 12038、11792 个事件。
两者均采用 64×64×64 Tanh 隐藏层、float64、2000 轮及相同主要训练参数；原方案为三输入，新方案增加 NaIID。

| 独立 Eval 指标（MeV） | 能量输入 Left | ADC 输入 Left | 能量输入 Right | ADC 输入 Right |
|---|---:|---:|---:|---:|
| MAE | 0.618380 | 0.619782 | 0.629784 | 0.718445 |
| RMSE | 1.763748 | 1.754026 | 1.899591 | 1.947852 |
| 中心 68% 半宽 W_68 | 0.565797 | 0.587299 | 0.574330 | 0.693515 |

Left 的 RMSE 变化 −0.55%、W_68 增加 3.80%；Right 的 RMSE 增加 2.54%、MAE 增加 14.08%、W_68 增加 20.75%。
因此总体误差量级接近，但右臂核心精度仍需检查；当前单次训练不足以判断差异是否稳定。

实验对照已核对同一批 39860 个事件的 SourceEntry、espriSide 和传统重建激发能；模型文件 SHA256 与推理记录一致。
固定局部拟合窗口为基态 [−1,1] MeV、第一激发态 [2.3,4.3] MeV，结果如下（高斯 sigma ± 拟合统计误差）：

| 重建方法 | 基态 sigma（MeV） | 第一激发态 sigma（MeV） |
|---|---:|---:|
| 传统实验重建 | 0.6788 ± 0.0255 | 0.6698 ± 0.0111 |
| 能量输入 MLP | 0.7361 ± 0.0320 | 0.6944 ± 0.0124 |
| ADC 输入 MLP | 0.7301 ± 0.0314 | 0.7131 ± 0.0133 |

ADC 与能量输入的两峰宽度接近，未显示一致改善；这些是同一批事件的相关结果，不能将误差按独立测量简单合并来判断显著性。
局部单高斯 sigma 不等于探测器本征分辨率；基态拟合偏差统计量/自由度约为 3–7，仍需检查峰形与拟合窗口依赖。
数据依据：`ADC_output/metrics.json`、`Eval/evaluation.json`、`Exp/PeakFits.json` 及上级对应能量输入结果。

## 如何理解这一步

在物理解域内，给定棒号和 A、B、C，能量与连续 ADC 是确定的可逆变换，反算本身不会增加独立的探测器信息。
当前测试验证了网络能处理这种非线性表示；有限网络的学习效果仍可随表示和归一化变化。
当前模拟 ADC 继承已有能量响应，未独立生成两端光收集、光电子统计和电子学信号，因此还不能验证真实 ADC 响应建模的收益。

## 接下来要进行的内容

1. **先做受控比较**：对照 `[ENaI, rdcX, rdcY, NaIID]` 与 `[ADC, rdcX, rdcY, NaIID]`，固定样本、划分和主要训练设置，区分 ADC 替换与增加棒号的影响。
2. **检查右臂差异**：按 NaIID、能量和 RDC 位置检查残差、Bias、W_68 与尾部；重复不同训练种子，判断当前差异是否稳定，不用 Test 选模型。
3. **以实验约束响应模型**：整理各棒两端 ADC 的位置依赖、增益/衰减、噪声及阈值/饱和等信息，明确模拟尚缺少的响应及可用约束。
4. **先建立双端数字化模型**：从模拟能量沉积及位置生成两端 Q，再按实验同样的几何平均、有效性和筛选流程构造输入；避免只重复能量到 ADC 的确定性换元。
5. **再决定完整光学模拟范围**：若简化响应模型无法描述实验中的位置依赖或分布，再加入所需光学过程，并检验其与已有展宽是否重复计入。
6. **重新训练并验证收益**：响应参数用校准数据约束；模型选择如有需要另设验证集，保留独立测试样本，最后比较完整误差指标和同事件实验激发能谱。

Geant4 提供了几种 C++ 类，让用户自己实现数字化模拟；以下为后续开发可参考的接口，当前尚未实现：

| Geant4 类 | 功能 |
|---|---|
| G4VHit | 存储粒子的能量沉积等 Hit 信息 |
| G4VDigitizerModule | 数字化模块的抽象基类 |
| G4VDigi | 表示数字化后的信号，例如 ADC |
| G4TDigiCollection | 保存一个事例中的数字化信号 |
| G4DigiManager | 注册、管理和调用数字化模块 |

Geant4 接口说明参见[官方 Digitization 文档](https://geant4.web.cern.ch/documentation/dev/bfad_html/ForApplicationDevelopers/Detector/digitization.html)；数字化模块需由用户实现并调用。
