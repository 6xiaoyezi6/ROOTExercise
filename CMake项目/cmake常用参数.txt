cmake -S <源码目录> -B <构建目录>
cmake -S . -B build            

-S .：源码目录是当前目录，里面应该有 CMakeLists.txt
-B build：把生成的构建文件放到 build/

-D变量名=值
cmake -S . -B build \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_CXX_STANDARD=17

cmake --build build

cmake --build build --parallel 8 并行编译
cmake --build build --target MyApp 指定编译目标
