如果数据始终满足“一条全局直线 + 每层相同的独立高斯误差”，Kalman 和最小二乘在数
  学上基本等价，无法合理地体现 Kalman 的精度优势。你目前得到几乎相同的结果正是正
  确现象。

  即使没有磁场，也可以通过以下真实效应体现 Kalman 的优势。

  ### 最推荐：加入多重散射

  粒子经过探测器材料时，即使没有磁场，也会发生多重散射，使斜率在层与层之间产生小
  变化：

  第1层 ─── 第2层 ─── 第3层
            散射后斜率变化

  此时轨迹不再是唯一的一条全局直线，而是“局部直线”。

  Kalman 状态仍可使用：

  state = [y, slope]

  传播矩阵：

  F = {{1, deltaX},
       {0, 1}}

  在层与层之间加入过程噪声 Q，例如：

  Q = scatteringVariance *
      {{deltaX * deltaX, deltaX},
       {deltaX,          1.0}};

  这样：

  - 最小二乘只能拟合一条折中的全局直线；
  - Kalman 可以逐层更新局部位置和局部斜率；
  - 散射越明显，Kalman 的预测残差通常越小。

  ### 加入不同层的测量分辨率

  让不同漂移室层具有不同的测量误差：

  sigma = {1.0, 2.0, 0.8, 3.0};
  R = sigma[i] * sigma[i];

  Kalman 可以逐层使用不同的 R：

  residualVariance = predictedPYY + measurementVariance[i];

  测量精度高的层获得更大权重，精度差的层权重更小。

  不过公平比较时，应该将 Kalman 与“加权最小二乘”比较。加权最小二乘在线性、无过程
  噪声条件下仍然与 Kalman 等价。

  ### 加入异常点并使用 innovation 筛选

  例如让 5% 的击中点产生较大偏移：

  if (random.Uniform() < 0.05) {
      y += random.Gaus(0.0, 20.0);
  }

  Kalman 更新前计算归一化残差：

  double normalizedResidual2 =
      residual * residual / residualVariance;

  if (normalizedResidual2 > 9.0) {
      // 超过约 3 sigma，跳过这个测量点
      continue;
  }

  这样异常点不会明显拉偏后续轨迹。普通最小二乘会被异常点影响，但需要与鲁棒最小二
  乘进行公平对比。

  ### 加入缺失层

  让某些漂移室层没有击中：

  if (random.Uniform() < 0.1) {
      continue;
  }

  Kalman 可以直接从上一层传播到下一层：

  deltaX = nextX - previousX;

  不过最小二乘也能处理缺点，因此它更多体现 Kalman 的逐层处理便利性，而不一定直接
  提高精度。

  ### 建议的模拟方案

  最适合你当前代码的修改是：

  1. 使用固定且分离的漂移室层位置，例如：

  x = {-40, -20, 0, 20, 40};

  2. 每经过一层，让真实斜率产生小的随机变化：

  slope += random.Gaus(0.0, scatteringSigma);

  3. 每层使用不同的测量误差。
  4. 加入约 5% 的异常点。
  5. Kalman 使用：

  R[i] = sigma[i] * sigma[i];
  Q != 0

  6. 使用归一化 innovation 拒绝异常点。

  评价指标建议改为：

  - 每一层位置预测偏差；
  - 最后一层之后的外推位置误差；
  - 局部斜率偏差；
  - 异常点存在时的拟合成功率；
  - 参数 pull 是否接近均值 0、宽度 1。

  最关键的一点是：加入多重散射后，不再只有一个全局 trueSlope。应该保存每层的
  trueSlope[i]，比较 Kalman 在每一层得到的局部斜率。这样即使没有磁场，也能最清
  楚、最合理地体现 Kalman 的优势。
